# 番茄时钟 Pomodoro

两个番茄工作法计时器的实现，同一套功能设计：

| 目录 | 实现 | 技术栈 |
| --- | --- | --- |
| [pomodoro-web](pomodoro-web/) | 网页版 | 零依赖纯前端，双击即用，可离线 |
| [pomodoro-ios](pomodoro-ios/) | iOS 原生 App | SwiftUI，含 XCTest 单元测试 |

## 功能

- **三种模式**：专注 / 短休息 / 长休息，默认 25 / 5 / 15 分钟，可自行调整
- **自动循环**：专注结束自动开始休息（可关）；每完成 4 个番茄进入长休息（间隔可改）
- **控制**：开始 / 暂停 / 重置 / 跳过（跳过不计入统计）
- **可视化**：环形倒计时、周期圆点、阶段主题色
- **提醒**：提示音 + 通知（web 版 Web Audio / iOS 版系统音 + 本地通知）
- **记忆**：设置与状态持久化，回到应用时结算「离开期间已结束」的阶段

## 架构

两个版本共享同一套核心设计：**纯逻辑状态机 + 时间注入**。

- 时间逻辑与 UI 分离，核心不取真实时钟，`tick(state, now)` 由调用方传入时间
- 单元测试可以「快进 26 分钟」而无需真实等待
- 运行中只保存结束时间戳，暂停冻结剩余、恢复重算终点——后台/切前台不累计漂移

各目录内有独立的 README 与测试说明。
